This is a WarioWare-style game involving two minigames. The first is a platformer minigame in which the player plays as Poko, a quirky character with a garlic obsession, and tries to collect all the garlic before the time runs out. The second is a clicker minigame in which the player must click all five garlic before the time runs out. The player is allotted five lives. Lives can only be lost if a minigame is not completed in time.
This project involved minimal generative AI use. AI, specifically ChatGPT, was used only to generate two in-game backgrounds and one sprite.
This game was made for the Hack Club Stardance Challenge.
Try it on the web browser at https://leijo17.itch.io/pokoware
